ReKindle Browser Probe

Open this page on the e-reader. It checks the JavaScript and CSS features ReKindle needs, then makes real requests for manifest.json so the network results are not guesses.

Running tests...

The critical row is XHR GET manifest. If it does not say OK 200, ReKindle's login, sync, chat and online apps cannot work on this browser, because the fetch() polyfill is built on XMLHttpRequest.

On the Legacy build, a YES for AbortController, TextEncoder, TextDecoder, String.matchAll, Element.prepend and canvas.toBlob can come from the injected shims rather than the engine itself. The two manifest rows are real network requests.
